# Samantha Crawford — Teaching Portfolio

A static, six-page teaching portfolio built with HTML and CSS.

## Pages

- `index.html` — Home
- `about.html` — Background, teaching philosophy, education, and certifications
- `experience.html` — Professional experience and embedded résumé
- `classroom.html` — Classroom routines and instructional strategies
- `projects.html` — Makerspace projects and technology leadership
- `contact.html` — Direct contact information

Open `index.html` in a browser to view the site. The résumé preview and PDF export link use the provided Google Slides presentation and require its sharing permissions to allow access.
